# DENK DEUTSCH / Deutschraum — German Revision Motion Graphics

Interactive German learning and revision materials for Grade 11 STEM students, plus a cinematic motion-graphics film ("DENK Deutsch — G11 Mid Revision") used as a revision aid.

## Contents

- `index.html`, `deutschraum-open.html`, `deutschraum-studio.html` — browser-based German learning/revision pages.
- `film/` — motion-graphics production sources.
- `out/` — rendered video output (generated, not committed).
- `QCREPORT.md` — quality-control report for the rendered film.

## Technology stack

- **Frontend:** HTML, CSS, JavaScript.
- **Media:** Canvas/SVG motion graphics rendered to MP4 (H.264/AAC).

## Running locally

Open `index.html` in a modern browser. The rendered film is not included in the repository; see `QCREPORT.md` for render details.
